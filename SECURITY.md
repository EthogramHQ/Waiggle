# Sécurité / Security

## Signaler une faille

Merci de **ne pas** ouvrir de ticket public. Utilisez le signalement privé de GitHub :
onglet **Security**, puis **Report a vulnerability**.

Décrivez la faille, comment la reproduire et son impact. Nous accusons réception sous 7 jours
et vous tenons informé de la correction.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting: **Security** tab, then
**Report a vulnerability**. Include steps to reproduce and the impact. We acknowledge reports
within 7 days.

## Périmètre / Scope

La branche `main` et la dernière version déployée. / The `main` branch and the latest deployment.
